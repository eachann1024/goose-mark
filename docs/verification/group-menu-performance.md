## 五路对抗及最终独立复审

五个并行代理均使用次旗舰 `gpt-6.1-sol`，分别负责 [混乱用户](chaos-user.md)、[奇怪输入](weird-input-user.md)、[慢速用户](slow-user.md)、[狡猾用户](sneaky-user.md)、[首次用户](first-user.md)。代理早期快照/屏蔽事件的限制保留在原记录中；主代理对最终核心交互使用生产页面复验。第六个独立代理最终只读复审，本轮追加发现并修复批量清空同步的重复查找及过宽跳过查找的共享目标回归，再审通过；在修复重复锚点索引、小键失败迁移、删组默认位置及新建默认分类后，未发现其覆盖调用链内其他有证据的 P1/P2；不把源码审查写成宿主运行通过。

## 实现依据和最终检查

比较了 [TanStack Virtual](https://github.com/TanStack/virtual) 与 [react-window](https://github.com/bvaughn/react-window)（检索时均为活跃 MIT 项目）：采用窗口、overscan、稳定 key 和测量设计，结合既有多子组锚点、可变描述与 dnd-kit 自行桥接，没有复制不兼容来源代码，也没有引入新运行依赖。

Impeccable 最终 detector 输出 35 个 advisory（既有 CSS 的 18 色值、15 圆角、2 弹性 easing）；逐项对照本轮 CSS diff，告警不在新增 UI 规则中，未为消告警改动无关视觉。[输出](evidence/final-impeccable.json)。现有设计记录于 `DESIGN.md`。

最终 `bun run type-check`、`git diff --check`、`bun run build` 均通过；构建已包含默认分类、清空/同步及旧格式迁移/自动清理修复。Vite 对未来 native config loader 和大 chunk 的提示保留为既有构建建议，没有把构建成功写成真实宿主验收通过。

## 批量清空补充取证

同一合成数据和计数同步替身下，只测真实 trash action（不含真实 share helper），100k 条从 161.41ms 降为 13.80ms，8.55%；这是本轮 action 前后对照，不是整个清空交互的端到端比例。[数据](evidence/empty-action-before-after.json)。随后改用真实 trash + share helper，内容提交仍为内存替身、同步运输仍为计数替身，得到上表 29.04ms / 296.99ms；两组 fixture 不同，不能把它们混作同口径前后比例。保留 readonly、空回收站、遗留多子组/重复索引/孤儿 ID 的记录；空回收站由原提交 1 次改为 0 次。

实际页面 UI 使用少量合成记录验证业务结果；大数据计时是无 React 订阅者的真实 action 模块 Eval，**不包含真实 Zustand commit 的持久化调度、可视提交或网络队列**，不代替百万清空端到端验收。边界记录共四次 lookup：两次通用删除、一次 null 内容更新和一次不存在 ID 更新，均属预期回退；实际大批删除的剩余数组 lookup 为 0。

## 旧格式迁移补充取证

自动清理当前唯一内部调用在 `migrateFromLegacy` 的旧嵌套格式分支结束处；**普通 `loadFromSnapshot` 不调用它**。本轮两处重复扫描分别位于迁移去重与后续清理，不把这次优化描述为所有快照加载都变快。Set 去重仍保留第一条同 ID 记录和各子组 ID 原顺序；清理仍只根据索引保护正常引用，不借此次优化重写既有位置声明。

计时是单次样本，包含真实 action 算法，不含 React 提交、真实宿主、磁盘恢复副本或网络；组合 Eval 的 set/commit 和 ensureValidSelection 为内存替身。实际页面只用少量合成旧格式记录，调用真实 store 方法并渲染结果。日期边界对照固定逻辑 Date.now 以比较完全相同的过期阈值；所有性能计时使用真实 performance.now，性能采样没有替换时钟。来源和对象引用不变验证保留在原始记录。

连续轮次复核后，本会话仍没有可调用的 LCU 原生 `js/js_reset` 工具；CLI 安装及状态正常输出不代表已能操作 uTools。EGO 当前页预算为 8，实际第九页已失败；本轮核对 taskSpace 的公开选项只有 profileId，没有提页数选项。真机与同时10页验收需先改变外部工具配置，不能用其他被禁止的原生控制方式或额外任务空间绕过。已通过的类型检查与最终构建日志见 [typecheck](evidence/migration-typecheck.log)、[build](evidence/migration-build.log)。
