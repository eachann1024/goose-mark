# 慢速与大数据窗口化验证记录

## 完整应用：百万单子组

EGO taskSpace 8 的 p5，应用开发页面内注入 100 万条仅在内存中的模拟书签和一个空分组。浏览器无 uTools 数据库，未写用户书签数据库。网格约三列，默认 overscan 2；以下是实际浏览器观察，不代表所有设置或宿主均已通过。

- 中段：滚动后首见 `slow-499923`，相对内容区顶部 -126.5px，挂载 48 项。切到空分组再返回，首见 ID、偏移和 scrollTop（5999439）一致。
- 尾部：首见 `slow-999981`，偏移 7.5px，末项 `slow-999999` 可见，挂载 28 项。切组返回后首见 ID、偏移和 scrollTop（12000090）一致。
- 真实方向键：从 `slow-0` 连续按 18 次向下，选中 `slow-54`，稳定后选中项在视口内，挂载范围为 `slow-36` 至 `slow-83`。此过程跨过初始窗口；未以 Enter 打开外链。
- 刷新恢复：浏览器无持久化数据库，先将内存中的分组记录临时写入 localStorage 模拟宿主存储，刷新页面并重新注入相同模拟数据；之后恢复了原 localStorage。中段首见 `slow-499923`、-126.5px 一致；尾部首见 `slow-999981`、7.5px 一致且末项可见。实际 uTools 数据库的写入与重启仍需宿主复验。
- 小数据真实鼠标拖拽：采样期间页面多次前后台切换，dnd-kit 收到 visibilitychange 后会取消拖拽。临时屏蔽这一事件的条件下，同段 `small-0` 从第 1 位移至第 3 位；`small-1` 跨段插在 `small-7` 前；`small-2` 移入空段；按 Escape 后顺序未变且收到取消提示。这些结果验证落点行为，但前后台切换条件下的实际拖拽仍受限；未验收触摸拖拽。
- 重复书签 `dup-0` 同时位于两个子组时，在第二子组的首见位置切组后返回，仍显示第二子组，偏移由 -3.5px 变为 -4px；模拟刷新后仍在第二子组，偏移 -3.5px。持久锚点包含子组和下标，旧格式仍可读取。
- 最终源码复验百万列表切组：中段 `slow-499910`、-8.5px 和尾段 `slow-999986`、7.5px 在返回后保持一致，尾项 `slow-999999` 可见。
- 390px 宽、1000 条长短描述混排：列表和两列网格跳至首、中、尾后均有可见条目，末项可见。5000 字描述在单行省略模式测得高度约 16.5px。此为离散位置观察，未证明快速连续滚动期间始终无空白；完整描述模式未复验。
- 真实 React 组件 Eval：在同一批次定位旧结果外窗第 800 项并替换为 1000 条新结果，滚动中段后可见 `B494–B505`。数据或布局变化时清除未完成定位，并设置有界的定位超时，避免窗口停滞。

## 组件模拟及风险

- 此前的独立组件模拟曾在手机宽度、4 倍 CPU 限速下直接滚动到底并看到第 999999 项；另曾离线验证两列网格末项、可变高度宽度变化和隐藏恢复。这些记录早于近期锚点与 overscan 改动，不能作为最新版的完整应用复验。
- 每个子组保留外壳，物理行高共享约 1200 万像素预算；可见行使用真实高度，前后占位映射逻辑高度。每段最多缓存 512 条测量；未测量行仍为估算。采用已测最小行高扩大窗口，但长短描述混排、改变密度及尺寸后快速滚动仍需实测，不能保证期间无空白或跳动。
- [滚动记忆](../../src/views/home/useHomePanelPersistence.ts) 记录首见书签 ID、视口偏移和是否到底；[恢复逻辑](../../src/views/home/useHomePanelRestoration.ts) 使用锚点定位，避免重启丢失模块缓存后仅依靠压缩物理位置。若书签被删除、布局变化或存在多个不同高度子组，行为仍需进一步验收。
- 当前无独占生产环境下的 50ms 帧耗时证据；触摸拖拽、手机连续快滚、离线、完整描述可变高度和实际宿主持久化仍待验证。
