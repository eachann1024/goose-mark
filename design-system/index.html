Foundations

暖纸、珊瑚与一点衬线。

所有新项目的默认风格。暖象牙底色、珊瑚强调、AI 专用紫、Newsreader 衬线标题 + DM Sans 正文。克制但不冷淡：界面干净，每个交互都有明确反馈。

使用方式：复制 design-system/tokens.css 到新项目，在 <html> 上设置 data-theme 和 data-density，组件样式从本页 <style> 的 Components 段直接取用。

01
内容即界面

去掉不直接服务任务的装饰，让内容本身成为视觉主体。

02
键盘即主人

高频操作都有键盘路径，焦点状态清晰可见。

03
密度可调

紧凑 / 标准 / 宽松三档，默认偏紧凑高效。

04
瞬态反馈

反馈在 150ms 内出现，不打断主任务流。

05
排版即层级

用字号、字重、字体区分层级，不依赖颜色或边框。

Color

颜色

三种角色色，各有单一职责：珊瑚用于主操作、选中、链接；紫只用于 AI 触点；绿 / 红只表达状态。其余全部是暖中性色。

Rules

规范与禁忌

这样做
  • 层级先靠字号、字重和衬线/无衬线区分，再考虑颜色。
  • 珊瑚只出现在主操作、选中态、链接与焦点环上。
  • AI 相关入口、状态、加载统一用紫色。
  • 默认扁平；只有浮层（菜单、Toast、对话框）用 shadow-pop。
  • 颜色写成 hex / rgba，兼容旧 Chromium（uTools、Electron）。
  • 文字对比度 ≥ 4.5:1，关键交互保留可见焦点。
不要做
  • 渐变文字、玻璃拟态作为默认装饰。
  • Material 式厚重阴影和浮起卡片。
  • SaaS 仪表板式的大数字 metric 卡片和 hero 区。
  • 密集树状列表、过小点击区、多层嵌套缩进。
  • 纯白正文配纯黑底；深色模式用 #eae8e1 / #090a0c。
  • 悬停用位移抬升（会让命中区抖动），改用 scale。
