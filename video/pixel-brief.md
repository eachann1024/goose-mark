# 鹅的书签 · AI 创建 —— 像素点阵版导演简报

观看目标：31 秒内让人看懂「丢一段话 → AI 找网址、抓取、翻译、精简、归组 → 一张书签卡」。

## 1. 规格

| 项 | 值 |
| --- | --- |
| 引擎 | Remotion 4（复用本目录工程，新增 Composition `GooseAIPixel`，不改旧 `GooseAI`） |
| 画布 | 1080 × 1080（1:1），60 fps |
| 时长 | 1860 帧（31 s），不循环，末 90 帧定格 |
| 输出 | `out/goose-ai-pixel.mp4`，H.264，CRF 18，yuv420p，+faststart，AAC 192k |
| 音频 | `scripts/make-pixel-audio.mjs` 代码合成 → `public/audio/pixel.wav` |

## 2. 视觉系统

### 2.1 像素点阵

- 全画面是一张 **LED 点阵**：网格步距 `PITCH = 12px`，90 × 90 格，原点 (0,0)，点为圆角方形，边长 8px、圆角 2px。
- 熄灭点始终可见（`DOT_OFF`），所有图形 = 点亮的点。没有任何连续矢量线、渐变、阴影、模糊、描边。
- 静止元素的点必须吸附到网格（坐标取整到 PITCH）；只有「飞行中」的物体允许离格，落地瞬间吸回。
- 图形（图标、窗口框、卡片、开关、鹅）用 0/1 位图定义，在点阵上绘制。
- 文字也用点阵：把字串画到离屏 canvas，再按步距采样成点（阈值 alpha > 0.45）。文字层使用更细的步距，见 2.3。

### 2.2 配色（十六进制，仅以下 6 色）

| Token | Hex | 用途 |
| --- | --- | --- |
| `BG` | `#0B0B0D` | 背景 |
| `DOT_OFF` | `#18181C` | 熄灭点 |
| `DIM` | `#4A4A52` | 次要点（被淘汰内容、熄灭轨道） |
| `DIM_HI` | `#9A9AA4` | 未选中的分组名 |
| `INK` | `#F2EFE6` | 主点亮色 |
| `ACCENT` | `#FF5A1F` | **唯一强调色**：网址、AI 扫描线、数字上限、新建标记、开关开启 |

同屏 ACCENT 面积不超过点亮点总数的 15%。

### 2.3 字体（采样前的源字体）

| 角色 | 字体 | 字重 | 字号 | 字距 | 采样步距 / 点边长 |
| --- | --- | --- | --- | --- | --- |
| 标题 H | `"PingFang SC"` | 600 | 100px | 6px | 6px / 4.6px |
| 正文 B | `"PingFang SC"` | 500 | 48px | 3px | 4px / 3.2px |
| 网址 / 英文 U | `"Menlo"` | 700 | 44px | 0 | 4px / 3.2px |
| 大数字 N | `"Menlo"` | 700 | 260px | -4px | 8px / 6.4px |

- **最小字号 44px 等效，全片不允许任何小字。**
- **四角禁区**：画面四个角各 200 × 200px 内不得出现任何文字或图形点亮点（只允许熄灭点）。
- 标题统一水平居中，基线在 y = 236；内容区在 y 320–900。

## 3. 动效参数（集中写入 `src/pixel/motion.ts`）

### 3.1 三次贝塞尔

| 名称 | 曲线 | 用途 |
| --- | --- | --- |
| `OUT` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、点亮扩散 |
| `INOUT` | `cubic-bezier(0.65, 0, 0.35, 1)` | 位移、扫描线、变形 |
| `IN` | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场、内爆 |

禁止使用线性 interpolate 做任何可见运动（逐点时间偏移的 stagger 序号除外）。

### 3.2 弹簧（mass = 1，stiffness = 180，damping = 2ζ√(k·m)）

| 名称 | 阻尼比 ζ | damping | 用途 |
| --- | --- | --- | --- |
| `SNAP` | 0.55 | 14.76 | 开关拨杆、卡片落位，允许一次可见回弹 |
| `SETTLE` | 0.85 | 22.81 | 卡片飞行、窗口展开，几乎无回弹 |
| `FIRM` | 1.0 | 26.83 | 文字归位，无回弹 |

### 3.3 时长（帧，60 fps）

| 名称 | 帧 | 说明 |
| --- | --- | --- |
| 1 拍 | 30 | BPM 120，所有镜头切点落在拍上 |
| 标题入场 | 18 | 点从中心列向两侧逐列点亮，`OUT` |
| 标题退场 | 12 | 逐列熄灭，`IN` |
| 逐点 stagger | 0.6 帧/列 | |
| 转场重叠 | 6–12 | 见第 4 节 |

## 4. 镜头表（每镜头只有一个主运动）

| # | 帧范围 | 标题 H | 主运动 | 画面 | 衔接到下一镜 |

## 5. 音乐与音效（全部代码合成）

- 调性 F 大调，BPM 120，与画面拍点对齐（30 帧 = 1 拍，切点都在拍上）。
- 和弦进行 F–C–Dm–B♭，每和弦 2 小节，循环。
- 声部：
  - 主旋律：12.5% 占空比脉冲波，八分音符琶音，短包络（A 2ms / D 120ms / S 0），-14 dBFS。
  - 贝斯：三角波，四分音符根音，-12 dBFS。
  - 鼓：正弦下扫 kick（150→45Hz，120ms）落在 1、3 拍；白噪声高通 hi-hat 落在反拍；镜 1 只有琶音，镜 2 起加入鼓，营造递进。
  - 音效：网址变 ACCENT 时上行 3 音 blip；窗口展开时噪声 whoosh 200ms；粒子重组时 16 个随机高音 tick；卡片落位时低频 thud；开关拨动时短 click；镜 8 落标时一个大三和弦琶音。
- 结尾：1770 帧起整体 90 帧淡出到静音。
- 48 kHz / 16-bit 立体声，峰值 ≤ -1 dBFS，轻微立体声展宽（琶音左右交替 ±20%）。

## 6. 禁用

- 任何角落小字：水印、时间码、帧号、页码、版本号、角标、品牌 bug、定位括号与注释。
- 全屏透明度交叉淡化、黑场淡入淡出（唯一例外：音频结尾淡出）。
- 模糊、发光、辉光、镜头光晕、投影、渐变、玻璃拟态、新拟态。
- 3D 旋转、透视翻转、相机抖动、缩放推镜带来的点阵抗锯齿重采样（点阵层只做整数位移）。
- 逐字弹跳、打字机闪烁光标、emoji、通用闪光 ✨ 图标。
- 线性缓动、Remotion 默认 spring 参数、超过 1 次回弹的弹簧。
- 第二个强调色、调色板外的任何颜色。
- 同一镜头两个以上同时主运动。

## 7. 质量保证

1. 静帧：每镜头取 `from+20`、中点、`to-8`，以及每个切点前后各 2 帧，共约 40 张，`remotion still` 输出到 `out/pixel-stills/`。
2. 联系表：`ffmpeg` tile 拼为 `out/pixel-contact.png`（每格 360px，带帧号仅出现在联系表里，不进成片）。
3. 检查：四角 200px 禁区无亮点（脚本自动统计）、文字可读、ACCENT 面积、无溢出、转场无空帧。
4. 修复后重新抽帧复核，再完整渲染；用 ffprobe 核对时长、分辨率、帧率与音轨。
