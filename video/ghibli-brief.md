# 鹅的书签 · AI 创建 —— 吉卜力版使用指引

用途：给 AI 功能的介绍视频，按真实操作顺序演示：唤出 uTools → 粘贴一段带链接的文字 → 选「AI 创建书签」→ 展开内部四步 → 保存成功并跳转到书签。

## 1. 规格

| 项 | 值 |
| --- | --- |
| 引擎 | Remotion 4，复用本目录工程，新增 Composition `GooseAIGhibli`，不改 `GooseAI` / `GooseAIPixel` |
| 代码目录 | `src/ghibli/` |
| 画布 | 1080 × 1080（1:1），60 fps |
| 时长 | 2160 帧（36 s），末 120 帧定格 |
| 输出 | `out/goose-ai-ghibli.mp4`，H.264，CRF 18，yuv420p，AAC 192k，+faststart |
| 音频 | `scripts/make-ghibli-audio.mjs` 代码合成 → `public/audio/ghibli.wav` |
| QA | `scripts/ghibli-qa.mjs` 抽帧 → 四角检查 → `out/ghibli-contact.png` |

## 2. 视觉

### 2.1 画风：《龙猫》夏日乡野

- 用代码绘制，不用图片素材，不画任何吉卜力版权角色（龙猫、灰尘精灵、猫巴士都不画）。只借画风：
  - 高饱和但柔和的夏日天空，堆积的积雨云，云的底部偏暖灰、顶部高光。
  - 前景大片稻田 / 草坡，远处一棵巨大的樟树剪影，树冠用多层圆团叠出。
  - 水彩质感：所有大色块叠 SVG `feTurbulence` + `feDisplacementMap` 做手绘毛边（scale 3–6，种子固定），再叠一层纸纹噪点（opacity 0.06）。
  - 线条：深墨绿 2.5–3px，手绘轻微抖动（固定种子，不随帧闪烁）。
- 鹅是品牌吉祥物：白色圆胖的鹅，橙喙，画成吉卜力式简洁造型，作为「AI 助手」在内部流程里出场叼走/搬运信息。
- **界面用页面样式渲染**：uTools 窗口和插件首页用 HTML/CSS 还原，参考 `../src/views/home/home.css` 和组件（搜索命令条 `usearch-strip` / `usearch-cmd`、toast、书签卡片），保持真实产品的布局与圆角，只在配色上融入画面（窗口为浅色，带柔和投影落在草地上）。窗口浮在风景前景中央，不是风景里的物件。

### 2.2 配色（只用这些）

| Token | Hex | 用途 |
| --- | --- | --- |
| `SKY_TOP` | `#5FA8D9` | 天空顶部 |
| `SKY_LOW` | `#BFE3F2` | 天空近地平线 |
| `CLOUD` | `#FBF8EE` | 云、窗口底色 |
| `CLOUD_SH` | `#D9D6CC` | 云阴影 |
| `MEADOW` | `#8DBF5A` | 草地亮部 |
| `FOREST` | `#3F7A3A` | 树冠、草地暗部 |
| `DEEP` | `#1F3D2B` | 线条、正文字色 |
| `PAPER` | `#F4EBD3` | 纸张卡片、内部流程面板 |
| `ACCENT` | `#E8602C` | **唯一强调色**：被识别的网址、鼠标点击涟漪、选中的命令项、字数上限、目标分组、成功勾 |

ACCENT 每屏面积 ≤ 10%。不使用其他颜色；半透明叠加只允许用上表颜色。

### 2.3 字体

| 角色 | 字体 | 字重 | 字号 | 字距 |
| --- | --- | --- | --- | --- |
| 镜头标题 | `"HanziPen SC"` | 700 | 72px | 4px |
| 面板正文 | `"PingFang SC"` | 500 | 34px | 1px |
| 界面文字（uTools / 插件） | `"PingFang SC"` | 500 | 30px | 0 |
| 英文原文 / 网址 | `"Menlo"` | 600 | 30px | 0 |
| 数字强调 | `"HanziPen SC"` | 700 | 160px | -2px |

- **最小字号 30px，全片没有小字、没有注释、没有角标、没有页码、没有水印、没有字幕条。**
- **四角禁区**：四个角各 180 × 180px 内不得出现任何文字或界面元素，只能是风景（天空、云、草）。
- 镜头标题统一居中，位于 y = 96–176，只在内部流程镜头出现，一句话 ≤ 10 字。

## 3. 动效

集中写入 `src/ghibli/motion.ts`。

### 3.1 三次贝塞尔

| 名称 | 曲线 | 用途 |
| --- | --- | --- |
| `OUT` | `cubic-bezier(0.22, 1, 0.36, 1)` | 入场、展开 |
| `INOUT` | `cubic-bezier(0.65, 0, 0.35, 1)` | 鼠标移动、镜头推拉、面板位移 |
| `IN` | `cubic-bezier(0.64, 0, 0.78, 0)` | 退场 |

### 3.2 弹簧（用阻尼比 ζ 表达，`damping = 2ζ√(k·m)`）

| 名称 | stiffness k | mass m | 阻尼比 ζ | 用途 |
| --- | --- | --- | --- | --- |
| `SOFT` | 120 | 1 | 1.0（临界） | 窗口、面板落位 |
| `BOUNCY` | 260 | 0.8 | 0.45 | 按键、命令项被点中、成功勾 |
| `FLOAT` | 60 | 1.2 | 0.3 | 鹅、叶子、卡片轻微漂浮 |

在代码里写 `dampingFromRatio(ζ, k, m)` 换算，不直接写死 damping。

### 3.3 时长（帧，60 fps）

| 动作 | 帧 |
| --- | --- |
| 鼠标移动一段 | 30–42 |
| 点击按下 / 回弹 | 6 / 10 |
| 点击涟漪 | 24 |
| 打字（逐字） | 每字 2 帧 |
| 面板展开 | 24 |
| 镜头衔接 | 18–24 |

鼠标：macOS 白色箭头指针，移动走 `INOUT` 且轨迹为轻微弧线（二次贝塞尔控制点偏移 40–80px）；按下缩放 0.9，伴随 ACCENT 涟漪。环境：云每帧水平漂 0.15px，草地用低频正弦摆动，始终存在但不抢戏。

## 5. 音频

`scripts/make-ghibli-audio.mjs`，纯代码合成 WAV（44.1kHz 立体声），时长与视频一致：

- 风格：轻快、温暖，久石让式田园小品的感觉（不引用任何真实旋律）。BPM 96，F 大调，3/4 拍。
- 声部：
  - 钢琴/八音盒主旋律：加法正弦（基频 + 2、3 次谐波），指数衰减 0.6s，五声音阶为主的原创旋律。
  - 拨弦伴奏：三角波 + 快速衰减，按 I–vi–IV–V 每小节分解。
  - 柔和长音垫：两个微失谐的正弦，低通，音量 −18 dB。
  - 结尾一组上行琶音收在主和弦，最后 2 秒淡出。
- 音效与画面同步（从镜头表的点击帧计算秒数）：鼠标点击用短木鱼声（正弦 1.2kHz，衰减 40ms）；键帽按下用柔和低音敲击；纸片/卡片飞行用滤波白噪声 whoosh；成功勾用两音上行风铃。
- 总电平峰值 −1 dBFS，无削波。

## 6. 禁用

- 默认 fade-in-everything、默认线性移动、默认 `spring()` 参数、默认 scale 0→1 弹出。
- 渐变按钮、霓虹光晕、玻璃拟态、紫蓝科技渐变、粒子特效、镜头光晕、旋转 3D。
- 四角任何文字、角标、页码、水印、Logo、时间码；全片任何小于 30px 的字；字幕条。
- 打字机光标闪烁以外的闪烁；随帧变化的抖动噪声（纹理种子固定）。
- 同屏多个主运动；鼠标瞬移；没有鼠标触发就自动发生的界面变化（环境动画除外）。
- 介绍设置项（允许新建分组等）。
- 吉卜力版权角色、真实吉卜力画面或音乐。

## 7. 质量保证

1. 抽帧：每镜头起始 +20、中点、结束 −8，每个衔接点前 2 帧和后 1 帧，以及最后一帧。
2. `scripts/ghibli-qa.mjs`：用 `@remotion/renderer` 的 `renderStill` 输出到 `out/ghibli-stills/`，统计每张四角 180×180 内是否有文字/界面像素（与该位置纯风景参考帧的差值超过阈值即报警），用 sharp 拼成 6 列联系表 `out/ghibli-contact.png`（每格下方标帧号，联系表本身不进视频）。
3. 逐张查看联系表：检查文字溢出、遮挡、四角、配色越界、鼠标是否先到位再触发、镜头衔接是否连贯；修复后重跑 QA。
4. 通过后完整渲染：`npm run ghibli:audio && npm run ghibli:render`。
