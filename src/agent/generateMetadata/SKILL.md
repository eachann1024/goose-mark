# 生成书签元信息

## 适用需求

- 为一个网址生成标题和简介。
- 根据已有页面标题与描述补全书签信息。

## 输入检查

- 必须有网址。
- 页面标题和页面描述可以为空。
- 联网兜底状态只用于判断来源。

## 输出

- 返回符合请求 Schema 的对象。
- `source` 只能是 `ai` 或 `network`。

## 质量要求

- 标题自然、准确，不超过 15 个汉字。
- 删除首页、登录、Documentation、官方文档等弱信息。
- 简介用一句话说明核心功能与价值，不超过 40 个汉字。
- 优先依据页面线索，不根据网址臆造细节。

## 完成

- 标题、简介和来源均满足 Schema 后结束。
