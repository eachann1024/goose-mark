# 管理书签

## 执行

- 打开书签前先搜索或读取并确认目标。
- 检查网址时调用 `checkBookmarkLinks`；401、403、429 只说明访问受限，不直接判定失效。
- 新增或修改书签、调整书签位置、增删改一级或二级分组时，先读取目标 id，再调用 `proposeChanges`。
- `proposeChanges` 只输出待确认清单。告诉用户需要在界面同意，不得声称已经修改。
- 新建书签优先使用用户指定分组；未指定时使用快速收集。
- 删除分组时说明受影响的子分组和书签归属。

## 完成

- 只读操作完成后说明结果。
- 写入提案生成后等待用户在界面确认。
- 打开成功后说明结果并停止。
